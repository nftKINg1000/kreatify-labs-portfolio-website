# Remotion portfolio films

Two original 15-second video compositions, built with React and Remotion:

- **AtelierPromo:** 1920 × 1080, 30fps, 15 seconds
- **FormaPromo:** 1920 × 1080, 30fps, 15 seconds

## Rendering

```bash
npm install
npm run studio
npm run render
npm run render:forma
```

Both are original animated *concept title showreels*, not real app-screen recordings. Replace conceptual headlines with verified screenshots or captured application footage before representing a production demo. Rendering requires Chromium/Remotion dependencies. Exported MP4s should be verified before portfolio use. Design language is Apple-inspired rather than an Apple product or endorsement.
