# Forma Finance

An original React Native + Expo demonstration of a personal-finance application. **Concept project, not client work.**

## Features
- Overview, activity, and goals views with interactive navigation
- Income/expense filtering and transaction list
- Local savings-goal contribution and quick-add transaction interactions
- Apple-inspired, original restrained interface: generous spacing, rounded cards, accessible contrast, system typography

## Run

```bash
npm install
npm run start
```

Requires a compatible Node.js environment and Expo Go, iOS Simulator, Android Emulator, or browser. No backend, banking credentials, real payments, or personal-finance data are involved. Data resets on reload.

## Production considerations
Add persistent encrypted storage, proper authentication, backend validation, accessibility testing, localization, actual data sources, app signing, privacy policy, and store review before any production use.

## Portfolio classification
Independent concept/demo; no implication of employment, client outcome, or app store publication.
