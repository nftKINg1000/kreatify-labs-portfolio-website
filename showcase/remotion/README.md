# Remotion showcase compositions

Source for two original 9-second, 720×1280, 24fps project video concepts.

- `FormaFinance`: independent React Native / Expo demonstration
- `KreatifyWeb`: React, TypeScript, Three.js website technology showcase

To render in a Remotion-capable environment install compatible `remotion` and `@remotion/cli` versions in a dedicated project and use:

```bash
npx remotion render showcase/remotion/index.ts FormaFinance out/forma-finance.mp4
npx remotion render showcase/remotion/index.ts KreatifyWeb out/kreatify-web.mp4
```

The supplied previews were rendered locally with FFmpeg because the Remotion npm packages were not available in the working environment. They are not pixel-identical exports of this component. This source is a reproducible Remotion-style composition, not a claimed successful Remotion build.

No copyrighted Apple branding/assets are used. Visual approach draws on broad platform principles: hierarchy, restraint, system typography, contrast and spatial clarity.
